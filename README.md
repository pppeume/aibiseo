# 🤖 AI 비서 "민지" - 회의 기록 자동 정리 시스템

> 회의 기록을 입력하면 **즉시 할 일 목록**으로 변환하는 AI 비서

## 🎯 개요

**"민지"**는 회의 기록, 메모, 이메일 내용을 입력받아 다음을 자동으로 정리해주는 AI 비서입니다:

- ✅ 5줄 요약
- ✅ 결정사항 정리
- ✅ 할 일 목록 (담당자, 마감일 포함)
- ✅ 확인 필요한 사항
- ✅ 오늘 바로 할 일 Top 3

## 🚀 빠른 시작

### 1. 설치

```bash
# 저장소 클론
git clone <repository-url>
cd aibiseo

# 의존성 설치
npm install
```

### 2. 실행

```bash
# 개발 모드
npm run dev

# 또는 일반 모드
npm start
```

서버가 시작되면 웹 브라우저에서 `http://localhost:3000`에 접속하세요.

## 📖 사용 방법

### 🚀 데모 모드 (추천)

API 키 없이 바로 체험:

1. 웹사이트 방문
2. "🚀 데모 모드" 선택
3. 샘플 중 하나 선택 (테스트 1, 2, 3)
4. "분석하기" 버튼 클릭
5. 결과 확인!

### 🔑 API 모드

실제 Claude API를 사용:

1. [Anthropic 콘솔](https://console.anthropic.com)에서 API 키 생성
2. 웹사이트의 "🔑 API 모드" 선택
3. Claude API 키 입력
4. 회의 기록 붙여넣기
5. "분석하기" 클릭

## 🎓 AI 비서 구조

### role.md (역할 정의)
AI 비서 "민지"가 무엇인지, 어떤 일을 하는지 설명합니다.

### workflow.md (업무 흐름)
사용자 입력부터 결과 출력까지의 전체 프로세스를 정의합니다.

### prompt.md (최종 프롬프트) ⭐
AI에게 주는 **최종 지시문**입니다. 여기에서 AI 비서의 모든 동작이 정해집니다.

**주요 특징:**
- 5단계 작업 순서 (요약 → 결정사항 → 할 일 → 확인사항 → 오늘 할 일)
- 결과물 형식 (마크다운)
- 금지 사항 (거짓 정보 금지, 지어내기 금지)
- 최종 점검 기준

### test-input.md (테스트 샘플)
실제 테스트용 회의 기록 3가지:
1. **테스트 1**: 제품 론칭 킥오프 회의
2. **테스트 2**: 고객사 미팅 기록
3. **테스트 3**: 팀 회의 메모

### output-template.md (결과 템플릿)
AI 비서가 출력하는 결과물의 표준 형식을 정의합니다.

# 🗂️ K-IoT PLUS 업무관리 (R&R 업무 기록·체크)

업무분장(R&R) 엑셀을 기준으로 **업무 표준화 → 주기별 업무 자동 생성·전달 → 처리 기록 → 달력/개인별 현황**을 관리하는 웹 화면입니다.

- 접속: 서버 실행 후 `http://localhost:3000/rr/`
- 저장: `data/rr-db.json`(업무 데이터), `data/uploads/`(첨부 파일) — `.gitignore` 처리되어 저장소에 올라가지 않습니다.

## 화면 구성

| 메뉴 | 기능 |
|---|---|
| ① 업무 표준 | 발생 시/매일/매주/매월/매분기/매반기/매년 탭별 업무 리스트. 대·중·소분류, 상세 업무, 메인·서브 담당자(다중 선택), 반복 주기(일·주·월·분기·년 × 간격, 기준일, 종료일, 사전 생성 일수, 주말 제외) 등록·수정, 일괄 확정/중지, 발생 시 업무 [발생 등록] |
| ② 업무 처리 | 생성된 업무 목록(담당자·역할·상태·기간 필터). 상세 화면에서 처리기한·완료여부 입력, 처리 현황 기록(타임라인), 파일 업로드/다운로드/삭제, 담당자 변경 |
| ③ 달력 | 월간 달력에 계획·예정·진행중·완료(+지연) 표시, 상태별 표시 on/off, 담당자 필터 |
| ④ 개인별 현황 | 기간별 담당자 집계표(계획/예정/진행중/완료/지연/완료율) + 개인 보드(상태별 카드) |
| ⚙ 기준정보 | R&R 엑셀 가져오기, 담당자 관리, 주기 업무 생성 즉시 실행, 상태 정의 |

## 동작 규칙

- **엑셀 가져오기**: '업무분장(R&R)' 시트의 대분류·중분류·소분류·상세 업무·자동화 여부·담당자(★=메인, ○=서브)·수행 주기·비고를 읽습니다. 같은 대·중·소분류는 갱신합니다.
  엑셀에 기준일이 없으므로 주기 업무는 **기준일 제안값**(월=말일, 분기=3·6·9·12월 말일, 비고의 `실행월` 반영 등)으로 채우고 **'기준일 확인 필요'(미사용)** 로 등록됩니다. 확인 후 확정해야 업무가 생성됩니다.
- **업무 생성·전달**: 확정된 주기 업무는 각 회차 `발생일 − 사전 생성 일수`가 되는 날 업무로 생성되고, 메인·서브 담당자 알림함(🔔)으로 전달됩니다. 서버 기동 시와 1시간마다 실행됩니다.
- **상태**: 계획(생성 시점 전인 미래 회차) → 예정(생성·전달됨) → 진행중(처리 현황 입력 시 자동 전환 또는 수동) → 완료. 처리기한이 지난 미완료 업무는 '지연'으로 표시됩니다.
- **기준일이 말일**이면 매 회차 말일로 생성됩니다(11-30 → 12-31 → 02-28). 반기는 '2분기마다'로 설정합니다.

## 제약 사항 (현재 버전)

- 로그인/권한 기능이 없습니다. 상단 '사용자'에서 본인을 선택하는 방식이며, **내부망 사용을 전제**로 합니다.
- 담당자 전달은 화면 내 알림함 방식입니다(이메일·메신저 발송 없음).
- 공휴일은 자동 제외되지 않습니다(매일 업무의 주말 제외만 지원).
- JSON 파일 저장소로 단일 서버·소규모 팀 사용을 전제로 합니다.
