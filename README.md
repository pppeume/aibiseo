# 🤖 AI 비서 "민지" - 회의 기록 자동 정리 시스템

> 회의 기록을 입력하면 **즉시 할 일 목록**으로 변환하는 AI 비서

## 🎯 개요

**"민지"**는 회의 기록, 메모, 이메일 내용을 입력받아 다음을 자동으로 정리해주는 AI 비서입니다:

- ✅ 5줄 요약
- ✅ 결정사항 정리
- ✅ 할 일 목록 (담당자, 마감일 포함)
- ✅ 확인 필요한 사항
- ✅ 오늘 바로 할 일 Top 3

## 🚀 빠른 시작

### 1. 설치

```bash
# 저장소 클론
git clone <repository-url>
cd aibiseo

# 의존성 설치
npm install
```

### 2. 실행

```bash
# 개발 모드
npm run dev

# 또는 일반 모드
npm start
```

서버가 시작되면 웹 브라우저에서 `http://localhost:3000`에 접속하세요.

## 📖 사용 방법

### 🚀 데모 모드 (추천)

API 키 없이 바로 체험:

1. 웹사이트 방문
2. "🚀 데모 모드" 선택
3. 샘플 중 하나 선택 (테스트 1, 2, 3)
4. "분석하기" 버튼 클릭
5. 결과 확인!

### 🔑 API 모드

실제 Claude API를 사용:

1. [Anthropic 콘솔](https://console.anthropic.com)에서 API 키 생성
2. 웹사이트의 "🔑 API 모드" 선택
3. Claude API 키 입력
4. 회의 기록 붙여넣기
5. "분석하기" 클릭

## 🎓 AI 비서 구조

### role.md (역할 정의)
AI 비서 "민지"가 무엇인지, 어떤 일을 하는지 설명합니다.

### workflow.md (업무 흐름)
사용자 입력부터 결과 출력까지의 전체 프로세스를 정의합니다.

### prompt.md (최종 프롬프트) ⭐
AI에게 주는 **최종 지시문**입니다. 여기에서 AI 비서의 모든 동작이 정해집니다.

**주요 특징:**
- 5단계 작업 순서 (요약 → 결정사항 → 할 일 → 확인사항 → 오늘 할 일)
- 결과물 형식 (마크다운)
- 금지 사항 (거짓 정보 금지, 지어내기 금지)
- 최종 점검 기준

### test-input.md (테스트 샘플)
실제 테스트용 회의 기록 3가지:
1. **테스트 1**: 제품 론칭 킥오프 회의
2. **테스트 2**: 고객사 미팅 기록
3. **테스트 3**: 팀 회의 메모

### output-template.md (결과 템플릿)
AI 비서가 출력하는 결과물의 표준 형식을 정의합니다.

## 🔒 보안

- ✅ API 키는 **브라우저 로컬 스토리지에만 저장**
- ✅ 서버로 전송되지 않음 (클라이언트 사이드 처리)
- ✅ 민감한 정보는 입력하지 않기
- ✅ 로그인/회원가입 불필요 (데이터 저장 안 함)

## 🛠️ 기술 스택

- **백엔드**: Node.js + Express
- **프론트엔드**: HTML + CSS + JavaScript
- **AI 모델**: Claude 3.5 Sonnet (Anthropic)
- **API**: Anthropic Claude API

## 💡 AI 비서 커스터마이징

### 프롬프트 수정
`ai-secretary/prompt.md`를 수정하면 AI 비서의 동작이 변합니다:

```markdown
# 역할
너는 내 회사의 영업 담당자입니다.

# 목표
고객 문의에 답변 초안을 만듭니다.

# 작업 순서
1. 고객 문의 요약
2. 감정 분석
3. 답변 초안 3개
...
```

### 이름 변경
- `prompt.md`의 "민지" → "다른 이름" 으로 변경
- `server.js`의 "AI 비서 직원 '민지'"도 동일하게 변경
