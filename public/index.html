업무분장(R&R) 엑셀 가져오기

'업무분장(R&R)' 시트의 대분류·중분류·소분류·상세 업무·자동화 여부·담당자(★ 메인 / ○ 공동수행)·수행 주기·비고를 읽어 업무 표준으로 등록합니다. 같은 대·중·소분류는 내용을 갱신합니다. 엑셀에는 기준일이 없으므로 주기 업무는 기준일 제안값으로 채워 '기준일 확인 필요'로 등록되며, 확정해야 업무가 생성됩니다.

담당자

주기 업무 생성

확정된 주기 업무는 각 회차의 발생일 − 사전 생성 일수가 되는 날 업무로 생성되어 담당자 알림으로 전달됩니다. 화면을 열 때와 열어 둔 동안 1시간마다 자동 실행됩니다.

상태 정의

계획확정된 주기 업무 중 아직 생성 시점이 오지 않은 앞으로의 회차 (캘린더·현황에 예측 표시) 예정업무가 생성되어 담당자에게 전달되었으나 착수 전 진행중처리 현황이 입력되었거나 담당자가 진행중으로 바꾼 업무 완료담당자가 완료 처리한 업무 지연처리기한이 지났는데 완료되지 않은 업무 (예정·진행중에 추가로 표시)
