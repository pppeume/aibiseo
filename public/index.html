업무 표준 (업무 리스트)

업무분장(R&R)의 대·중·소분류 업무를 주기별로 등록합니다. 주기 업무는 확정(활성)되면 기준일·주기에 따라 업무가 자동 생성되어 담당자에게 전달되고, 발생 시 업무는 [발생 등록]으로 생성합니다.

업무 처리

생성·전달된 업무입니다. 행을 누르면 처리기한·완료여부 입력, 처리 현황 기록, 파일 업로드를 할 수 있습니다.

업무 달력

계획(아직 생성 전인 주기 업무) · 예정 · 진행중 · 완료를 처리기한 날짜에 표시합니다. 처리기한이 지난 미완료 업무는 빨간색(지연)으로 표시됩니다.

개인별 업무 현황

기간 내 처리기한 기준으로 담당자별 계획·예정·진행중·완료·지연 건수를 집계합니다. 이름을 누르면 개인 업무 보드가 표시됩니다.

기준정보

담당자 관리, 업무분장(R&R) 엑셀 가져오기, 주기 업무 생성 실행

1. 업무분장(R&R) 엑셀 가져오기

'업무분장(R&R)' 시트의 대분류·중분류·소분류·상세 업무·자동화 여부·담당자(★ 메인 / ○ 공동수행)·수행 주기·비고를 읽어 업무 표준으로 등록합니다. 같은 대·중·소분류 업무가 이미 있으면 내용을 갱신합니다. 엑셀에는 기준일이 없으므로 주기 업무는 기준일 제안값으로 채워 '기준일 확인 필요' 상태로 등록되며, 확인 후 확정해야 업무가 생성됩니다.

3. 주기 업무 생성

서버는 기동 시와 1시간마다 자동으로 실행합니다. 각 회차는 발생일 − 사전 생성 일수가 되는 날 생성되어 담당자 알림함으로 전달됩니다.

상태 정의

계획확정된 주기 업무 중 아직 생성 시점이 도래하지 않은 미래 회차 (달력·현황에서 예측 표시, 자동 생성 대상) 예정업무가 생성되어 담당자에게 전달되었으나 아직 착수 전 진행중처리 현황이 입력되었거나 담당자가 진행중으로 변경한 업무 완료담당자가 완료 처리한 업무 지연처리기한이 지났는데 완료되지 않은 업무 (예정·진행중에 추가로 표시)
