# AI 비서 "민지" - 업무 흐름 (Workflow)

## 사용자 흐름

```
1. 웹사이트 방문
   ↓
2. Claude API 키 입력 (또는 미리 저장된 키 사용)
   ↓
3. 회의 내용/메모 텍스트 붙여넣기
   ↓
4. "분석하기" 버튼 클릭
   ↓
5. 로딩 표시 (2-3초)
   ↓
6. 결과 표시:
   - 5줄 요약
   - 결정사항
   - 할 일 목록 (표 형식)
   - 확인 필요한 사항
   - 오늘 바로 할 일 3개
```

## AI 비서가 하는 작업 순서

1. **입력 받기**
   - 사용자의 메모/회의 기록 수집
   - 글자 수 확인 (최소 50자, 최대 5000자)

2. **프롬프트 구성**
   - 저장된 "민지" 프롬프트 로드
   - 사용자 입력 삽입
   - Claude API에 전송

3. **AI 처리**
   - Claude가 프롬프트 실행
   - 구조화된 결과 생성

4. **결과 정리**
   - 섹션별로 포맷팅
   - 표와 마크다운 변환
   - 웹에 표시

5. **사용자 편의 기능**
   - 결과 복사 버튼
   - 다운로드 (마크다운, PDF)
   - 샘플 테스트 제공

## 성공 기준

- ✅ 회의 기록 입력 → 5초 내 결과 표시
- ✅ 할 일이 명확한 목록으로 보임
- ✅ 담당자와 마감일이 표시됨
- ✅ "확인 필요"는 지어내지 않고 표시됨
