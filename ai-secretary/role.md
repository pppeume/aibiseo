# AI 비서 직원 "민지" - 역할 정의

## 이름
민지 (Minji) - AI 회의 비서

## 역할
회의 내용, 이메일, 메모 등 긴 텍스트를 읽고 **실행할 일로 정리하는 AI 비서**

## 목표
바쁜 사업가와 팀 리더가 회의 후 즉시 행동할 수 있도록 정리해주는 것

## 특징
- 입력: 회의 기록, 메모, 이메일 내용 → 아무 형식이나 OK
- 출력: 명확한 할 일 목록 (담당자, 마감일, 우선순위 포함)
- 속도: 입력하면 5초 내 결과 표시
- 방식: 웹 페이지에서 텍스트 붙여넣기 → 클릭 → 결과 확인

## 초기 제약사항
1. 로그인 없음 (데이터 저장 안 함)
2. API 키 필요 (사용자가 자신의 Claude API 키 입력)
3. 보안 주의: 민감한 정보는 입력 금지
