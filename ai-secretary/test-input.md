## 테스트 1: 제품 론칭 회의 기록

### 입력값
```
[2026년 7월 8일 오전 10시 제품 론칭 킥오프 회의]

참석자: CEO 이순신, 개발팀장 김영희, 마케팅 담당 박진수, 디자인 리드 이지은

이순신 CEO: 안녕하세요. 우리 제품 AI 직원 플랫폼 정식 론칭을 위해 오늘 회의를 소집했습니다. 
지난주 베타 테스트 결과가 좋았어서 이번달 안에 론칭을 진행하기로 결정했습니다.

김영희 개발팀장: 현재 상황을 설명드리겠습니다. 핵심 기능은 90% 완료되었고, 버그 수정만 남았습니다. 
다만 결제 시스템 통합이 예상보다 복잡해서 2-3주 더 필요할 것 같습니다. 
보안 테스트도 마쳐야 하는데, 외부 보안 업체와 계약이 아직 안 됐습니다.

박진수 마케팅: 마케팅 측면에서는 준비가 거의 다 됐습니다. 
블로그 글 5개, SNS 콘텐츠 20개, 유튜브 영상 3개를 이미 만들었습니다. 
다만 론칭 공식 발표 자료를 CEO님과 검토해야 합니다. 
그리고 초기 구매자를 위한 프로모션 정책을 최종 확정해야 합니다. 예산은 500만원 정도 생각 중입니다.

이지은 디자인: UI 디자인은 완성됐고, 최종 QA 중입니다. 
모바일 반응형은 테스트 필요하고, 다크모드도 추가하면 좋을 것 같습니다.

이순신 CEO: 그럼 최종 일정을 정리해봅시다.
- 7월 25일까지 개발 완료 (결제시스템 포함)
- 7월 28일까지 보안 테스트 완료
- 8월 1일 공식 론칭
- 8월 5일 첫 주 매출 목표 1000만원

추가로, 김영희님은 개발팀 일정을 다시 검토해서 7월 25일에 가능한지 내일까지 확인해주세요. 
박진수님은 프로모션 예산 검토 후 내일 오전에 최종 안을 제시해주고, 
이지은님은 모바일 테스트를 우선으로 진행해주세요.

그리고 보안 업체 선정은 제가 담당하겠습니다. 오후 2시까지 3곳을 단축 리스트로 만들어서 
여러분께 공유하겠습니다. 그러면 내일 오전 회의에서 최종 선택하겠습니다.

회의는 여기까지입니다. 고생하세요!
```

## 테스트 2: 고객 미팅 이메일 요약

### 입력값
```
[고객사 A 미팅 기록 - 2026.07.08]

고객사: 이커머스 회사 X
담당자: 구매담당 김대리
우리쪽 담당: 영업팀 박과장

요청사항:
- AI 자동 상담 기능이 필요 (고객 문의 자동 답변)
- 주문 관리 자동화
- 재고 예측 AI
- 마지막 기한: 9월 말까지

고객사 예산: 구체적으로 언급 안 함 (예산 문의 필요)
계약금: 선결제로 진행 희망 (우리는 분할 제안 중)

다음 회의: 1주일 뒤 (7월 15일)
샘플 데모: 3일 내에 보내달라고 함

고객사 요구사항 우선순위:
1. AI 상담 기능 (가장 중요)
2. 주문 관리 (중요)
3. 재고 예측 (나중에 추가 가능)

우리 과제:
- 데모 영상 만들기
- 기술 사양서 작성
- 비용 예상 제시
- 계약 조건 협상
```

## 테스트 3: 팀 회의 간단한 메모

### 입력값
```
[7월 8일 오후 2시 정기 팀 회의]

1. 블로그 글 발행 일정
   - 이번주 3개 게시 예정 (유미가 담당)
   - 다음주는 5개로 늘리기로 결정
   
2. SNS 콘텐츠 성과
   - 지난주 인스타그램 팔로우 200명 증가
   - 틱톡 조회수 10만 돌파
   - 목표: 이번달 인스타 팔로우 1만명

3. 기술 문제
   - 서버 속도 이슈 있음 (개발팀 김팀장이 확인 중)
   - 데이터베이스 용량 부족 (내일까지 업그레이드 필요)

4. 신규 프로젝트
   - 새로운 AI 기능 1개 개발 시작 (아직 이름 미정)
   - 담당: 개발팀 (팀원 2명 배정)
   - 시작: 7월 10일

5. 다음 회의
   - 7월 15일 오전 10시 (정기 회의)
```
